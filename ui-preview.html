Your code
var maxSubArray = function(nums) { let max = nums[0]; let cur = nums[0]; for (let i = 1; i < nums.length; i++) { cur = Math.max(nums[i], cur + nums[i]); max = Math.max(max, cur); } return max; };
My thinking
I attempted brute force O(n²) initially, tracking all subarray sums. Realized it's too slow for large inputs but couldn't figure out the optimal pattern on my own.
Right thinking
Kadane's algorithm: iterate once, keeping a running sum. At each position, decide whether to extend the current subarray or start fresh. The max of all running sums is the answer. O(n) time, O(1) space.
Notes
Key insight: if the running sum drops below 0, reset to 0. The subarray always starts at a positive position.
