Two Sum II — Sorted Array
arrays two-pointers medium
Think about the approach, then rate your recall:
Your code
var twoSum = function(numbers, target) { let l = 0, r = numbers.length - 1; while (l < r) { let sum = numbers[l] + numbers[r]; if (sum === target) return [l + 1, r + 1]; if (sum < target) l++; else r--; } };
Right thinking
Since the array is sorted, use two pointers from both ends. If sum < target, move left pointer forward. If sum > target, move right pointer backward. O(n) time, O(1) space.
